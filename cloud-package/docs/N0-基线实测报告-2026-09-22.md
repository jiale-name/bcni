## 五、口径与局限（读数字前必看）

1. **单点探测 ≠ 压测结论**。本报告的 Redis 吞吐是**单连接串行**、Reranker 延迟是**单次调用**、云通道是 **TCP 建连 RTT**（不含 TLS / HTTP / 排队）。它们只用于建立基线量级，不能替代 IDX-04/05/11 的压测。
2. **Embedding 吞吐的「份/分钟」需换算**。报告给的是「单条文本 / 秒」，乘以 CL-3 分块方案的「单元数 / 份」才是需求 §6.1④ 的「份/分钟」；分块方案定稿后请在本报告追加一行换算结果。
3. **同一次运行内的数值不可横向比较**。首次调用含模型加载（bge-m3 在 CPU 上尤甚），本脚本通过逐轮换文本 + 多次采样尽量摊平；若数值明显异常，请加 `--embedding-rounds` 重跑。
4. **本报告不含任何凭据**。凭据只输出「已配置 / 未配置」；如发现报告中出现密钥，属渲染层缺陷，请立即反馈。
